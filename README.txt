Sitio estático basado en el catálogo oficial ubicado en:
Atry Lab\Sitio Web

Abrir index.html o ejecutar ABRIR_PAGINA_LOCAL.cmd para ver la página.

Archivos:
- index.html: estructura y contenido visible.
- styles.css: estilos, colores y version movil.
- script.js: productos, filtros y armado de consultas.
- recursos: logo, tipografías, iconos, imágenes y librerías locales.

No usa Next, React, Vinext ni npm. Solo HTML, CSS y JavaScript.

ESTUDIO 3D DE LA PORTADA
- printer.js: impresora modelada en 3D, iluminación, cámara y ciclo de fabricación.
- printer.css: presentación del estudio y adaptación móvil.
- recursos/librerias/three.min.js: Three.js r160, guardado localmente, con su licencia MIT.
- recursos/trazar-isotipo.cjs: herramienta opcional para reproducir el contorno del isotipo desde el PNG oficial.
La escena no descarga modelos ni texturas y no necesita un proceso de compilación.
Incluye pausa manual, respeta la preferencia de movimiento reducido y suspende
el render al salir de pantalla o cambiar de pestaña. Si WebGL no está disponible,
se muestra el isotipo como alternativa estática.
